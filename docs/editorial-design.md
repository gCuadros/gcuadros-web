# Personal editorial direction

The current direction puts Gonzalo’s name, an introduction and his public work ahead of credentials. The homepage order is introduction, Hevy, technical note, talks, experience and education, contact. Existing case URLs, language routes and CV downloads remain intact.

The background is warm paper (#F7F5EF), with dark green ink (#203D35), readable secondary text (#4C5750) and green links (#285C46). The former copper/dark palette, decorative three-point signature, generic capability rows and all-caps technical labels have been removed. The Hevy flow remains because it explains the actual project. Links have visible underlines; focus and reduced-motion behavior are preserved.

Newsreader is used for names, headings and the introductory paragraph; Manrope for prose and navigation. IBM Plex Mono is reserved for code. Fonts remain self-hosted; no new animation or client dependency was added. The desktop introduction has a short current-role sidebar; mobile uses one reading column. The note, talks and trajectory use different layouts according to their content.

The reference https://maggieappleton.com/ informed the emphasis on authored material and reading hierarchy. This portfolio does not reuse its illustrations, brand, copy or layouts. No fabricated screenshots or project metrics are used.

The native Pen.dev Q/R boards contain the desktop/mobile direction and are edited only through the official MCP. The design file and private continuity documents remain local. They are not website assets. Older A–P boards document previous iterations, not the current public direction.

Social previews and favicon use the same palette. Validation covers both languages, mobile and desktop overflow, keyboard navigation, automated accessibility, article/case journeys and language-specific CV downloads. Visual review is still necessary; passing checks does not establish aesthetic quality.

Public content must not add headcounts, internal migration routes or company infrastructure diagrams. AWS, Azure, Kubernetes and Ansible belong to academic training unless professional use is explicitly confirmed.
