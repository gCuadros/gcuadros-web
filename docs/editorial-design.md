# Editorial design

The portfolio uses Newsreader for display headings, Manrope for body text and navigation, and IBM Plex Mono for short technical labels. Newsreader is self-hosted through next/font/local from the pinned Fontsource package (SIL Open Font License 1.1). Only the normal Latin variable font is loaded; it includes Spanish characters.

The editorial hierarchy and reading rhythm were informed by https://maggieappleton.com/. The palette, content, diagrams and composition remain specific to this portfolio; no illustrations or commercial fonts were copied.

Headings: 88px desktop, 64px tablet, 46px mobile; body text: 17px desktop, 16px mobile. Dark charcoal, warm white and copper retain the existing identity. Technical annotations use a quiet side rule. The featured talk uses an asymmetric two-column layout on desktop and stacks on small screens.

Links and buttons use 200ms colour transitions. Link arrows move 2px on hover/focus. Reduced-motion disables transitions and transforms. Content stays visible without animation or JavaScript. No scroll interception or animation dependency is used.

Public content describes transferable skills. Do not add headcounts, internal migration routes or company infrastructure diagrams. AWS, Azure, Kubernetes and Ansible belong to academic training unless professional use is explicitly confirmed.
