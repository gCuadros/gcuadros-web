# Decisiones iniciales

- Next.js App Router y TypeScript estricto: permiten un sitio principalmente estático, ampliable con artículos y casos de estudio.
- Componentes de servidor por defecto: evitar JavaScript de cliente salvo interacciones que lo necesiten.
- CSS nativo y tokens: una interfaz pequeña no necesita una biblioteca de componentes adicional.
- Fuentes del sistema: la compilación no descarga fuentes de terceros y la primera carga no depende de ellas.
- Contenido inicial en español, coherente con el perfil actual. Inglés pendiente de decisión.
- Sin analítica, cookies de seguimiento ni formulario con backend en esta primera entrega.
- Se añadirá validación de navegación y accesibilidad con la interfaz definitiva.
